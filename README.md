# 第三項

シェアオフィスの一室を歩き、物を調べ、残っている人に話して、最後に告発するブラウザゲームです。この README に筋書きは書いていません。

## 同じWi-Fiのタブレットで開く

このパソコンをWi-Fiにつなぎ、`Wi-Fiで開く.bat` をダブルクリックします。窓に出たアドレスを、同じWi-Fiのタブレットのブラウザに入力します。

このパソコンだけでは、次のアドレスでも開きます。

`http://127.0.0.1:8084/`

止めるときは、開いた窓を閉じるか、Ctrl+C を押します。ほかの端末から開けないときは、`Wi-Fiで開く.ps1` を右クリックして「管理者として実行」を一度だけ選びます。

Python が必要です。

## 遊び方

部屋を移動し、物を調べ、人に話します。調べた事実はノートに残ります。最後に、誰が、どの説明が崩れるか、どの手口かを告発します。

ヒントは三つまでです。答えを見るは、作者が確認するためのものです。進行は、そのブラウザの中に残ります。最初から、で消せます。

## 作者用

`脚本.md` は作者用です。配信用の `www` の外にあります。遊ぶ人には渡さないでください。タブレットへ出すときも、`www` だけが配信されます。

## GitHub Pages

リポジトリを作ったあと、Settings の Pages を GitHub Actions にします。`main` へ push すると、`www` だけが公開されます。

公開アドレスは https://usksasuke-sys.github.io/daisankou/ です。

`脚本.md` は `.gitignore` に入っています。このパソコンには残し、リポジトリには入れません。

## 公開するとき

指示があるまで、Netlify には上げません。上げるときは、`www` だけをサイトに置きます。ビルドコマンドは不要です。公開ディレクトリは `www` の直下です。`脚本.md` は含めません。
